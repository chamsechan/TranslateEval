# 准确率口径与逐语种结果查阅

准确率统一为「正确数 / 总样本数」。得分大于等于阈值为正确；评分失败、取消、等待评分、评分中和缺失评分记录均计为未通过，保留原状态供排查。加权平均准确率按各语种总样本数加权，宏平均准确率对全部语种等权。平均分仍只基于成功评分样本。

## 页面操作

1. 在「评测结果」点击「分析结果」，顶部查看加权平均准确率、正确数和总样本数。
2. 「各语种评测结果」列出各语种的正确数、准确率、评分覆盖率、平均分及未评分数。
3. 点击语种或「查看明细」进入该语种全部句子；点击未评分数量进入该语种未评分明细。
4. 在「逐句评分明细」组合选择语种、状态、分数比较方式和得分。例如选择 `th`、`小于 <`、`8` 查看泰语低于 8 分的句子，选择 `等于 =`、`0` 只匹配实际评分为 0 的句子。
5. 展开句子核对源文、中文 GT、候选译文、原始分数、评分理由、完整异常信息和尝试次数。「清除筛选」恢复全部样本。准确阈值和明细分数筛选独立生效。
