# 可编辑导入与下拉选项维护

数据集和推理结果导入增加“读取文件 → 编辑信息 → 核验 → 提交”的流程。`dataset_info.json` / `result_info.json` 在界面导入时可选：有文件时预填，没有文件时填写表单。支持直接上传 JSONL，也兼容原目录及 ZIP 示例。

“模型与评价设置 → 导入下拉选项”集中维护模型、设备、平台、精度 / 量化位宽、推理模式。支持新增、修改显示名称、启用和停用；检查点使用文本输入。导入表单可以直接打开维护窗口，关闭后刷新选项并保留未提交内容。JSON 中的新选项值在成功提交后登记，已有历史运行的选项在启动时补入。

单个预测 JSONL 可以选择任意已导入数据集及版本；目录中的多个预测文件按数据集子目录分别选择版本。版本哈希自动带入，仍严格检查样本 ID 完整覆盖、重复、未知 ID 和空译文。没有提供语种声明时从样本汇总语种，已有声明仍需要覆盖样本使用的语种。

推理模式支持自定义值，并维护是否统计语种识别结果。核验时将统计行为保存在 `inference.detects_language` 中；后续修改选项不会改变已经核验或提交的信息。旧记录仍兼容 `mode=auto_detect` 的判断方式。原有一次核验的 API 保持兼容。

数据库新增迁移 `0003`，只增加选项表。已有环境按 README 的升级流程执行 `.venv/bin/alembic upgrade head` 并重启；`scripts/start.sh` 会执行迁移和前端构建。
