# 表格排序交互评审

结果展示表统一采用同一列连续点击三次的操作：**升序 → 降序 → 默认**。表头箭头显示当前方向；切换到另一列时从升序开始。第三次点击取消该列排序，并恢复该表原有顺序。

## 覆盖范围

| 表格 | 可排序内容 | 默认顺序 |
| --- | --- | --- |
| 评测结果列表 | 模型运行、数据集与版本、加权平均准确率、已评分平均分、评分状态、提交时间 | 最近提交优先 |
| 各语种评测结果 | 语言对、正确数、准确率、已评分数、覆盖率、平均分、未评分数 | 接口返回的语言顺序 |
| 逐句评分明细 | 样本 ID、源语种、候选译文、分数、评分状态、判定、来源、说明 | 数据集样本原始顺序 |
| 模型结果对比 | 模型运行、数据集与评价器、状态、准确率、未评分数、分值范围、平均分及宏平均指标 | 所选结果顺序 |
| 数据集样本预览 | 样本 ID、语言对、源文、中文参考译文 | 样本原始顺序 |
| 模型记录 | 运行名称、模型族、版本、推理平台、模式、备注、提交时间 | 最近提交优先 |

操作、选择和展开列保持各自功能。显示“正确 / 总数”和“已评分 / 总数”的列分别按正确数、已评分数排序；准确率和覆盖率有独立的比例排序列。语言对按原语种代码排序，代码与中文名称同时显示。

## 行为与统计口径

- 分页接口先筛选、再对全部匹配数据排序，最后取当前页。排序切换返回第一页，保留语言、分数等筛选条件；结果列表的对比勾选也会保留。
- 数值按实际数值排序，不使用显示字符串。空分数在升序、降序都放在末尾，区别于真实零分；并列项保持稳定顺序。
- 结果列表、语种汇总、逐句评分、数据集页面的样本预览及模型记录把排序状态保存在 URL，刷新后继续使用；第三次点击删除排序参数。语种汇总修改阈值后也保留当前排序与页码。
- 评分判定跟随当前阈值：升序为未评分、未达标、正确。状态按任务生命周期排序。说明列使用实际显示的评分理由或异常信息排序。
- 准确率仍为正确数 / 全部样本数，未评分计失败。各结果使用自身评价修订的默认阈值计算列表准确率，已评分平均分继续只统计有效评分。
- 无需数据库迁移。数字指标排序复用摘要 SQL，避免把全部匹配样本加载到应用内存，列表查询数量不随当前页行数增长。
